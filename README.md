# YouPlayer2

**A powerful, offline audio and video player for Android — built on VLC.**

YouPlayer2 plays your local music and video files with full playlist support. No internet required, no ads, no accounts. Just your media.

## Features

- **Audio Player:** Play MP3, FLAC, AAC, OGG, WAV, and more
- **Video Player:** Play MP4, MKV, AVI, MOV, and more
- **Playlists:** Create and manage custom playlists for music and videos
- **Offline:** Works completely offline — no streaming, no cloud
- **No Ads:** Clean, ad-free experience
- **Support SGSS:** Built with love by the SGSS project

   ```bash
   git clone https://github.com/Walusimbi-Leon1/YouPlayer2.git
   cd YouPlayer2
   ```

2. Build the APK:
   ```bash
   ./gradlew assembleDebug
   ```
